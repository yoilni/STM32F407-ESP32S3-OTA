# STM32 APP A v1.1.2

- 用途：ESP32 双分区掉电回滚实机测试
- 目标芯片：STM32F407ZGT6
- APP 起始地址：0x08020000
- 文件大小：22,616 字节
- CRC32：8D0FD54E
- 初始 MSP：0x20020000
- 复位向量：0x080247A1
- 版本代码：0x010102
- 功能与已验证的 v1.1.1 保持一致，仅提升可见版本号。
- 启动后执行 3 秒自检，再开放 UART OTA/QUERY。
- PC13 保持高电平常亮。

## 断电测试

确认 ESP32 已打印 `Rollback backup ready: version=1.1.1`。在 WS2812B 紫色且 UART 进度未到 100% 时切断整机电源。重新上电后，ESP32 应检测 `INSTALLING` 状态并从备份恢复 v1.1.1。
