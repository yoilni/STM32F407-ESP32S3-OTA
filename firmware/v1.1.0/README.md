# STM32 APP A v1.1.0

- 目标芯片：STM32F407ZGT6
- APP 起始地址：0x08020000
- 文件大小：22,724 字节
- CRC32：57793500
- 初始 MSP：0x20020000
- 复位向量：0x08024809
- 版本代码：0x010100
- 启动后先执行 3 秒自检，再开放 UART OTA/QUERY。
- QUERY 回报当前 APP 版本代码，供 ESP32 确认新固件真正运行。
- 启用约 8 秒独立看门狗并持续喂狗，启动故障会复位进入 Bootloader。
- PC13 保持高电平点亮逻辑和 500 ms 闪烁。
