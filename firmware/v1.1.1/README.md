# STM32 APP A v1.1.1

- 目标芯片：STM32F407ZGT6
- APP 起始地址：0x08020000
- 文件大小：22,616 字节
- CRC32：0B84288C
- 初始 MSP：0x20020000
- 复位向量：0x080247A1
- 版本代码：0x010101
- 修复 v1.1.0 在 IWDG/LSI 启动前等待更新状态位而卡死的问题。
- 正确顺序为：启动 IWDG/LSI、开放配置、设置分频与重装值、等待更新、重装计数器。
- 启动后执行 3 秒自检，再开放 UART OTA/QUERY。
- QUERY 回报当前 APP 版本代码，供 ESP32 确认新固件真正运行。
- PC13 保持高电平常亮。
